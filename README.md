# 📍 Location Analyzer for Retail Business

Professional online tool for analyzing retail business locations with investment calculations, revenue forecasting, and profitability analysis.

## Features

✅ **Comprehensive Analysis**
- Analyze 40+ location parameters
- Calculate revenue, profit, and ROI
- Automatic address detection via OpenStreetMap
- Population analysis by radius (50-500m)
- Crime rate and safety analysis
- Investment calculation with payback period
- 8+ expert recommendations

✅ **Business Templates**
- Cafe/Restaurant
- Clothing Store
- Services (Salon, Barbershop)
- Fast Food

✅ **Payment Integration**
- YooKassa payment gateway
- Premium detailed reports (899₽)
- Automatic report generation
- All payment methods supported (cards, SBP, Apple Pay, Google Pay)

✅ **User Experience**
- 5 analysis tabs
- Beautiful responsive design
- Mobile-friendly interface
- Real-time calculations
- HTML report download
